then re-run 93b". Branch `engine-phase`. **This IS a performance task:** PREAMBLE rule 9 (warm steady state) applies.
ONE change: the sky-ray exit below. No other march change, no default change for shells, mask, caches or tiers.

## Why (read first, targeted)
- `tools/overnight/blocked/93b4-shell-march-cost.HANDOFF.md`: at walk_near 5.8% of pixels (the top-right sky) run the
  primary shell march at ~94 iterations each; their SIMD groups wait, so few pixels cost ~13.7 ms. That task's option (b)
  was "end upward sky rays at a per-shell max-solid height".
- `tools/overnight/blocked/93b-shells-perf-breakdown.HANDOFF.md` (re-run, 2026-10-17): shells ON +12.7 / +13.9 ms p50
  standing (walk_near / walk_open); the shell march ~16-18 ms vs tiers 1-2 ~4 ms.
- `tools/overnight/blocked/93b5-shell-air-brick-mask.HANDOFF.md`: the air-brick mask (`-shellmask 1`) did NOT pay; it
  stays OFF. Measure with it OFF.

## Change
A ray that is RISING (dir.y > 0) and already ABOVE the highest solid voxel the remaining shells can hold cannot hit any
shell: stop the shell march there and go on as a no-hit (sky / whatever runs after a shell no-hit today).
1. Keep a conservative max-solid Y per shell (or per coarse x/z region of a shell if that is cheap; your choice, say why):
   updated on every `ShellStore.Store` (also `replace: true` redraws, ops and edit summaries) and never lower than any
   stored solid or fluid voxel. The far band / no-hit path must see the same t it sees today when the shells would have
   returned no hit, so the result stays EXACT: a ray that skips the rest of the march must be one that would have missed
   all of it.
2. CPU twin in `ShellRayReference.March` + tests (new `ShellSkyExitTests`): random rays over stored shells, the exit on
   vs off give the same hit / no-hit and t; a store that raises a column raises the bound; a ray grazing just above
   the bound.
3. Flag `-shellskyexit 0|1`. **Default ON only if** (a) the shot comparison is byte-identical (or <= 1 LSB with the
   reason) AND (b) it is faster at BOTH poses beyond the noise floor. Otherwise leave it OFF and say why.
