# Phase 7 preset review package

Nine fixed scenes, shot identically under every preset. **No preset is
recommended here and none is marked as a favourite** -- that is the owner's
call and the whole reason this package exists.

Every folder also has a `tonemap/` set. Read that FIRST if you are deciding
anything: until this stage there was no tonemapping in the renderer at all,
so every earlier judgement of these presets was made through a hard clamp.

Shot at 1920x1080, shadow rung 0, RELEASE build.

- **Warm/** — sun-dominant golden hour; the direct answer to §8
- **Atmospheric/** — soft, wide penumbra, warm/cool split -- closest to the brief
- **HighContrast/** — near-hard shadows, deep ambient, dramatic
- **Muted/** — low-saturation, even, the safe floor
- **Shipped/** — tonight's values, for A/B -- CLIPS SNOW AT NOON
